# Showcase

> [README로 돌아가기](../README.md)

## 주요 기능

### 📊 역량 분석
- Solved.ac ID 입력 후 3초 안에 풀이 패턴 분석
- **Radar Chart**와 **강점/약점 태그**로 시각화

### 🤖 AI 코드 리뷰
- **시간/공간 복잡도**: Big-O 계산과 근거 설명
- **라인 해설**: 코드에 Hover하면 구현 의도를 설명
- **알고리즘 패턴**: DP, DFS 등 사용 기법 자동 태깅

### 🌲 스킬 트리
- 게임처럼 알고리즘 스킬을 해금하며 학습
- 선행 개념을 익혀야 상위 문제에 도전 가능
